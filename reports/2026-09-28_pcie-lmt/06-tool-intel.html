Intel LMT:三種模式與廠商參考實作

Intel 的 PCIe Lane Margin Tool 是四者中唯一有正式使用手冊的工具(文件編號 639433,Rev 1.2,2026-06)。它同時支援 Windows 與 Linux,提供從手動除錯到自動化迴圈的三種執行模式,也是目前對 PCIe 6.0 描述最具體的公開文件。[5]

輸入參數字典

參數說明預設 / 建議來源

Dwell_Time每個 margining 步之間的等待秒數1 秒(規格建議)[5]

input_dic = {
  "Lane": [0,3], "RecNum": 6, "Dwell_Time": 1,
  "BDF_DSP": "B89D02F0", "BDF_USP": "B8aD00F0",
  "ErrCnt": 4, "Num_Time_Steps": "", "Num_Voltage_Steps": "",
  "Segment": 1, "Speed": 5, "Time_Start_Step": 3, "Voltage_Start_Step": 3
}

# 範例 2:全部 lane、DSP 側(Rx=1)、只掃到規格最小值、16 GT/s
input_dic = {
  "Lane": [0,1,2,3], "RecNum": 1, "Dwell_Time": 1,
  "BDF_DSP": "B89D02F0", "BDF_USP": "B8aD00F0",
  "ErrCnt": 4, "Num_Time_Steps": "6", "Num_Voltage_Steps": "32",
  "Segment": 0, "Speed": 4
}
★ 建議 · ★ 量產時的兩個建議(取自手冊敘述與規格)
  • 把 Num_Time_Steps / Num_Voltage_Steps 填成固定值,不要留空——留空代表「掃到壞為止」,每次量測的停止點不同,資料無法比較。[5]
  • dwell 與 ErrCnt 依手冊建議(1 秒 / 4)先跑出基準,再依自家良率與量測時間預算調整。[5]

lane reversal 四種情境

這是實際接線方向造成的坑:若埠支援 lane reversal,而工具的 lane 編號對不上,就會出現「讀不到 margin 能力」而失敗。手冊用四種組合說明:[5]

情境Execute_Lane_Reversal指定的 lane結果來源
1False0,1,2,3埠支援 lane reversal,但工具未做反轉 → 找不到能力,失敗[5]
2False4,5,6,7指定到反轉後的實際 lane → 找到能力,可正常 margining[5]
3True0,1,2,3工具嘗試反轉 → 找到能力,可正常 margining[5]
4True4,5,6,7埠不支援反轉,但工具仍嘗試 → 依設定繼續嘗試 margining[5]
★ 排錯 · 實務判斷法

出現「找不到 margin 能力」時,先不要懷疑硬體:換另一組 lane 編號或切換 Execute_Lane_Reversal 再試一次。[5] OCP 版則用另一種策略:以 lspci -tv/pci_crawler 先把實體拓樸畫出來再指定 lane。[2]

結果檔案與欄位

執行後會在 LMT 資料夾下的 PCIe_LMT_Results 產生 .csv 與 .txt。[5]

欄位區塊內容來源
鏈路識別(前 11 欄)裝置、接收器、鏈路與被量的 lane 資訊[5]
時間 margin以步數、時間(ps)與 %UI 表示[5]
電壓 margin以步數與電壓(mV)表示[5]
失因(fail cause)時間與電壓各自的失敗原因[5]
輸入參數等於本次使用的 input_dic 內容,便於回溯[5]
裝置能力本次讀到的 margin device capabilities[5]

三種停止 margining 的條件[5]

  1. 出現 failure(讀到的 Margining Lane Status 非預期值)[5]
  2. 達到時間/電壓步數上限(使用者指定值或裝置宣告能力值)[5]
  3. 錯誤計數達到 ErrCnt 門檻[5]
解讀 · NA 欄位的來源

結果中出現 NA 不是資料缺失,而是由裝置能力決定:未支援「Independent Left/Right Timing」時,時間結果只會有一側;未支援「Independent Up/Down Voltage」時同理。判讀前先對照能力欄位。[5]

Windows 驅動安裝(摘要)

  1. 從 PCI-SIG 官網(開發者/合規計畫頁)下載「PCI-SIG Hardware Access Driver」,必須是 0.1.43 版;1.42 之前可能與 LMT 不相容[5]
  2. 裝置管理員 → 動作 → 新增 legacy 硬體[5]
  3. 選擇「從清單手動安裝(進階)」→ 下一步[5]
  4. 點「從磁片安裝」→ 瀏覽到驅動目錄下的 pcisig_driver.inf[5]
  5. 完成安裝後,於裝置管理員的「系統裝置」確認出現「PCI-SIG Hardware Access Driver」且版本為 0.1.43[5]
